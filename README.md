# 🌏 Karry旅行家

智能定制您的旅程 - 基于豆包AI的旅行规划助手

## ✨ 核心功能

- 🎯 **智能规划**：输入需求，AI生成个性化旅行方案
- 🖼️ **真实图片**：自动搜索并展示景点、美食、酒店的真实照片
- 🗺️ **地图导航**：每个地点都有一键跳转到高德地图
- 📊 **卡片展示**：精美的卡片式布局，支持景点/美食/酒店分类
- ⭐ **方案收藏**：收藏喜欢的方案到本地，随时查看
- 📄 **多种导出**：支持HTML、Markdown、复制文本、打印

## 🚀 快速开始

### 本地运行

```bash
# 1. 安装依赖
npm install

# 2. 配置环境变量
cp .env.example .env
# 编辑 .env 文件，填入你的豆包API密钥

# 3. 启动服务
node backend/server.js

# 4. 访问
# 浏览器打开 http://localhost:3000
```

## 🛠️ 技术栈

- **后端**：Node.js + Express
- **AI模型**：豆包大模型（doubao-pro-32k）
- **前端**：原生JavaScript + CSS3
- **图片搜索**：百度图片API
- **数据存储**：LocalStorage（本地收藏）

## 🔐 安全建议

1. **保护API密钥**：
   - 不要提交 `.env` 文件到Git
   - 使用环境变量管理密钥
   - 在部署平台的环境变量中配置

2. **HTTPS配置**：
   - 生产环境必须使用HTTPS
   - 免费部署平台自动提供

3. **访问限制**（可选）：
   - 配置CORS白名单
   - 添加访问频率限制
   - 实现用户认证

## 🆘 常见问题

### Q: 图片无法加载？
A: 检查网络连接，百度图片API可能被墙，会自动使用占位图

### Q: 方案生成失败？
A: 检查豆包API配置，确认API Key和Endpoint ID正确

### Q: 收藏的方案丢失？
A: 收藏存储在浏览器LocalStorage，清除缓存会丢失，建议定期导出

### Q: 如何自定义样式？
A: 编辑 `frontend/index.html` 中的CSS样式部分
