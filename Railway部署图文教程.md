## 📤 第2步：上传代码

### 2.1 在终端执行
```bash
cd /Users/karryfan/.box/Workspace/output/f8b18a19-89a6-4705-9440-b757d999289f/travel-planner-doubao

# 添加远程仓库（替换为你的地址）
git remote add origin https://github.com/你的用户名/karry-travel-planner.git

# 推送代码
git branch -M main
git push -u origin main
```

### 2.2 输入凭据
首次推送会提示输入用户名和密码：
- **用户名**：你的GitHub用户名
- **密码**：使用 **Personal Access Token**（不是GitHub登录密码！）

#### 如何获取Token：
1. 访问：https://github.com/settings/tokens
2. 点击 **Generate new token (classic)**
3. 勾选 **repo** 权限
4. 点击 **Generate token**
5. **复制Token**（只显示一次！）
6. 粘贴作为密码使用

### 2.3 验证成功
刷新GitHub仓库页面，能看到代码说明成功！
